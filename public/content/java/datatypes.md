# Data Types in Java

Java has two categories of data types: primitive and non-primitive.

## Primitive Types
- byte, short, int, long
- float, double
- char
- boolean

## Example
```java
public class DataTypes {
    public static void main(String[] args) {
        int num = 10;
        double price = 99.99;
        char grade = 'A';
        boolean passed = true;
        System.out.println(num + ", " + price + ", " + grade + ", " + passed);
    }
}
